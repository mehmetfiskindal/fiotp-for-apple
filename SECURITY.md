# Security Policy

FiOTP stores OTP secrets in a local AES-256-GCM encrypted vault. Never include
real vaults, OTP secrets, passwords, signing certificates, or notarization
credentials in an issue or pull request.

Please report suspected vulnerabilities privately to the repository owner
before public disclosure. Include reproduction steps and affected versions,
but use synthetic credentials only.

Only releases signed by the official FiOTP Developer ID and published through
the project's official release channel should be treated as official builds.
